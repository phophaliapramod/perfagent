# perfagent
Performance troubleshooting dashboard built with Streamlit and DuckDB, featuring service-specific thresholds, degradation heatmaps, incident timelines, evidence-based investigations, and optional OpenAI tool calling.

Introduction
PerfAgent helps engineers explore service performance, identify degraded periods, compare metrics with a baseline, and investigate correlated signals. Built incrementally with Codex, it uses synthetic hourly metrics and provides deterministic analysis without AI credits. Its optional OpenAI integration uses validated, read-only tools; live API behavior remains unverified due to quota limits.
